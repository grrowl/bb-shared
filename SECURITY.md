# Security policy

Please do not report security vulnerabilities in public GitHub issues.

Email [tom@chillidonut.com](mailto:tom@chillidonut.com) with a description,
steps to reproduce, and any suggested mitigation. I will acknowledge the
report, investigate it privately, and coordinate a fix before disclosure.

bb-shared handles bearer links and connects a public Worker to a local bb
server, so reports involving unauthorized access, link disclosure, scope
enforcement, Worker deployment, or tunnel authentication are especially
welcome.
